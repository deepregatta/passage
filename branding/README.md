# Passage brand assets

Vendored from deepregatta `branding/concept-01-navigation-instruments/passage`, 2026-07-16 (original kit kept there for traceability).
Concept: **Navigation instruments** — flat, reproducible geometry; wordmarks expanded to paths (Lato Heavy, SIL OFL); no text elements, fonts, rasters, or external deps.

## Production rules

- Primary family ink: `#14293C`
- Passage accent: `#D97706` with `#0E7490` field.
- Chart paper `#F7F5EF` is a presentation/background color only — never baked into primary assets.
- Color assets on pale neutral backgrounds; reversed assets on ink navy or dark photography; mono for single-ink printing and constrained UI.
- Below 40 px use the matching `icon-16/24/32.svg`, never a scaled-down full mark.
- Minimum wordmark width 120 px digital / 32 mm print; minimum full-mark size 40 px digital / 11 mm print.
- Clear space: one quarter of the symbol width on every side.
